What does ?-> protect you from, and how is ?? different?
 ?-> (Nullsafe Operator) protects from calling a method or accessing a property on a null object, which would otherwise trigger a fatal TypeError in PHP.

 ?? (Null Coalescing Operator) provides a fallback default value when a variable or array key is either null or undefined (unregistered).

What’s the difference between array_map and array_filter?
 array_map transforms every element in an array and returns a new array of the exact same length, while array_filter evaluates each element against a condition and returns a new array containing only the items that pass.

What’s the difference between git add, git commit and git push?
 git add stages your changed files to prepare them for saving, git commit permanently records those staged changes as a snapshot in your local repository history, and git push uploads those local commits to a remote repository like GitHub.
